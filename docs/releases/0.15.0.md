A map open in the editor can be linked to the command line and to an AI tool such as
Claude Code: what they change shows in front of you, one undo step each. `scmjs map edit`
changes units, locations, sprites and fog from a list of edits. The game's files chosen
by hand now need `patch_rt.mpq`, without which replays did not play as they were played.

## A map linked to the editor

- `scmjs map open ridge.scx --live` opens the map in the editor in your browser and keeps
  it linked while the command runs. A `scmjs` command that names the file, from any
  terminal, then reads what the editor has, unsaved changes included, and changes the map
  there.
- Each command is one step under **Edit ▸ Undo**, named after the command. The status bar
  shows **Linked**.
- The file on disk changes only on a save, and **File ▸ Save** in the editor writes the
  file itself, with no download.
- If you edit the map while a command is working on it, your edit is kept: the command
  changes nothing and asks to be run again.
- The link runs between the command and the browser on your computer, and nothing is
  sent anywhere else. The desktop app does not link yet, so `--live` opens the browser.

## AI tools

- An AI tool set up with `scmjs mcp` links a map with `editor_open`, and from then on its
  tools work on the map in the editor. You watch each change arrive and undo the ones you
  do not want.
- The model can use what is on your screen. `editor_state` tells it what you have
  selected and which part of the map is in view, `editor_show` brings a place into view
  and flashes it, and `editor_picture` is the map as the editor draws it, so the model
  needs no copy of StarCraft to look at the map.
- `map_units`, `map_locations` and `map_edit` list and change units and locations
  directly, so "make the units I have selected invincible" is two calls. There are 42
  tools, up from 33.
- If you edit while a tool is working, the tool starts again from the map as it is now.
- The new guide at [docs.scmjs.dev/ai-tools](https://docs.scmjs.dev/ai-tools/) covers
  setting up Claude Code, Cursor and Claude Desktop, what to ask, and every tool.

## The command line

- `scmjs map edit ridge.scx --edits edits.json` applies a list of edits to a map: units
  placed, moved, changed and removed, locations added, changed and removed, sprites
  placed and removed, and fog set. The edits are applied together. When one cannot be
  done, nothing is written and the error names the edit.
- `scmjs map units` and `scmjs map locations` list what a map has, with the index or
  number an edit names each by. `map units` filters by type, player or area.
- `map edit` reads no game files, so a position is used as given and a building is not
  moved onto the grid. Run `map check` afterwards.

## The game's files

- Choosing the game's archives by hand under **Help ▸ Game Data…** takes `patch_rt.mpq`
  with `StarDat.mpq` and `BrooDat.mpq`. The two alone hold unit costs and build times
  from before the game's patches, a Factory at 200 minerals for one, and a replay played
  from such a copy left the game that was played within minutes, with nothing to say so.
  Blizzard's map editor download already carried the patch.
- A copy made earlier from the two alone is marked in the Game Data dialog. Choose
  **Remove copy**, then the StarCraft folder or all three archives.
- The desktop app passes over a StarCraft folder that has the two archives and no patch,
  and the dialog says why.
- A mod's data set added from a folder with the two archives and no patch is laid over
  your patched copy of the game. With no patched copy to lay it over, the dialog says the
  data set was made without the patch.
- On the command line, the commands that play the game, such as `replay watch`,
  `map test` and `bot ladder`, refuse a folder without the patch and say what to copy
  in. `map preview` still draws the terrain, and `scmjs doctor` warns.

## Replays and guides

- A replay saved by `scmjs bot ladder` no longer shows 12/31/1969 under the map's name
  in Aftermath.
- The guide's Replays section has pictures, and Maps in git in the command line guide
  starts with putting a map in git and getting an old version back.
- At scmjs.dev, the feature counts now include the name of the mod in use.
  **Preferences ▸ Privacy** turns counting off.

## What a script will notice

- A command that names a linked map reads and changes the editor's copy, not the file.
  `--out` writes a file as always and leaves the editor alone.
- The commands that play the game exit with 2 on a StarCraft folder without
  `patch_rt.mpq`.

## For plugin authors

- A change that arrives through the link replaces the whole map as one undo step. A
  plugin hears `"document"` with the reason `"replace"`, as after a raw section edit,
  and the selection is cleared.
- `api.gameData.install` for the game's own copy needs `patch_rt.mpq` with the two
  archives, as the dialog does.
- `@scm-js/core` exports `UnitState`.
- The bundled Aftermath moves to 0.27.1.
- The API version stays 1.
