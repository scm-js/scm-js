A protected map whose archive is full of files nothing names can be saved again. An AI can
now play scenarios on a map to check its triggers, and give a map a TrigScript script.
`scmjs mcp` now serves only the map tools unless you ask for more, so read **AI apps** if
you use the mod, replay or account tools.

## Saving

- Some protected maps could not be saved at all: every Save failed with `MpqError`.
  Protectors fill the map's archive with files that nothing in the map names, so there was
  no room for the files the editor writes. The game never opens such a file, so when there
  is no room, Save now leaves them out and the map plays the same. The Save dialog says
  how many it leaves out.
- Repair 1.7.0 finds those files as a map opens and leaves them out of the next save, like
  its other safe repairs. **Undo** in Repair's list puts them back.

## Using the editor online

- A tab left open while scmjs.dev is updated keeps working. If part of the editor still
  cannot be downloaded, a notice says so and offers **Reload**, which keeps your recovery
  copies.

## AI apps

- **`scmjs mcp` serves the map tools and no others.** The mod, replay and scmjs.dev account
  tools are now sets you turn on: `scmjs mcp --tools all`, or `--tools mods,replays,account`
  for some of them. In Claude Desktop, tick the set in the extension's settings. 0.17.0
  served every tool, so add one of these if an AI used those tools for you. When a set is
  off, the AI is told how to turn it on.
- `map_test` plays scenarios on a map in the game and says what happened: each expectation
  with what the game gave, how the game ended and for whom, minerals and gas, the text
  shown and the triggers that fired. A scenario can be given inline, and `save` keeps it in
  the map's tests file.
- `map_script_import` gives a map a TrigScript script, or changes some of its files, and
  compiles it at once, with errors given as file, line and column. `map_script_export` gives
  the files back, and `map_script_api` looks up what a script can call.
- The Claude Desktop extension now includes TypeScript, so `map_build` works with nothing
  else installed.

## Command line

- `scmjs map test --show` prints what each game did. `--only <name>` plays one scenario,
  `-` reads scenarios from standard input and `--save` keeps them. `scmjs mod test` takes the
  same flags.
- `scmjs map script import`, `export` and `api` do what the AI tools of the same names do.
- A script compiles with TypeScript 6. TypeScript 7 and 5 cannot compile one, and
  `scmjs doctor` now says "too new" or "too old" for them. Install `typescript@6`, since
  `typescript` alone installs 7.
- For a Homebrew install, `scmjs about` and `scmjs doctor` give the update command as
  `brew update && brew upgrade scmjs`. `brew upgrade` alone may not see a new release for a
  day.

## Privacy

- When something goes wrong, the count the editor sends now also says which part of the
  editor it was in, such as which dialog, and for a map file's archive, which kind of
  problem it was. It still never sends the error's message, the map or a file name.

## Plugins

- Repair 1.7.0: files in a map's archive that nothing names, left out of the next save.

## For plugin authors

- `api.document.archive.unreachable()` counts the archive's files that nothing names, and
  `dropUnreachable({ asOpened })` leaves them out of the next save. Its result has `undo()`
  to put them back. Use `asOpened` only for a repair made as the map opens.
- The API version stays 1.
