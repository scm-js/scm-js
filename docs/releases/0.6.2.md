## Triggers and dialogs

- **The Trigger Editor no longer leaves stray strings in the map.** Typing a message, a
  sound path or a comment in the Trigger Editor or Mission Briefing added a string to the
  map for every keystroke — "H", "He", "Hel" and so on — and they stayed there even if
  you pressed Cancel. Text typed in these dialogs now reaches the map only on OK or
  Apply, and only the strings your triggers still use. Maps edited with an earlier
  version may hold such leftovers; **Scenario ▸ String Editor ▸ Delete unused** clears
  them.
- **The larger editors ask before throwing away your changes.** Nothing done in a dialog
  is in the undo history, so a stray Escape used to lose everything since the last Apply.
  With changes you have not applied, Escape, the close button or a click outside the
  dialog now asks **Discard the changes made in this dialog?** first; a second Escape
  goes back to editing. Cancel still closes at once. This covers the Trigger Editor,
  Mission Briefing, the String Editor, the Sound Editor, Switches, and the Unit, Upgrade
  and Technology Settings.
- **Typing stays quick on maps with thousands of triggers or strings.** Every keystroke
  in a trigger's comment or arguments redrew the whole trigger list, and every keystroke
  in the String Editor redrew the whole table. Only the row you are editing is redrawn
  now.

## Drawing

- **Scrolling draws only the ground that comes into view.** The view used to redraw
  every visible tile on each step of a scroll, which was heaviest zoomed out on a large
  map. It now moves the picture it has and draws the newly uncovered edge. At 150% zoom,
  and at 100% and above on a display scaled to 125% or 150%, the view is redrawn whole
  as before; those are the scales with the fewest tiles on screen.
- **Animations out of sight no longer redraw the view.** A unit or sprite animating
  anywhere on the map used to repaint the screen on every game frame. Only one in or
  near the view does now. Units placed together still animate in step.
- **Less work on every repaint.** The rulers are redrawn only when the view or the
  pointer moves along them, and units off screen are no longer sorted into drawing
  order.
- **Shadows keep up with their units.** An image that follows a unit's main graphic,
  such as its shadow, was drawn one animation frame behind it.

## For plugin authors

Nothing in the API changed. While the Trigger Editor or Mission Briefing is open, the
working list handed to a trigger claim's `locate` and `open` can hold a negative number
in an action's `text` or `wav` field: a string typed in the dialog that the map does not
hold until OK or Apply. Rows a claim has located are locked against editing, so a claim's
own triggers never carry one.
